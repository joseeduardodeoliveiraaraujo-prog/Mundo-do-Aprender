# assets/images

Imagens usadas nas atividades (ilustrações, fotos, pictogramas).

- Organize em subpastas por módulo: `emotions/`, `routine/`, `animals/`, `communication/`.
- Nomes em minúsculas, sem acentos e com hífen: `menino-feliz.webp`.
- Prefira `.webp` ou `.svg`; mantenha cada arquivo leve (idealmente < 200 KB).
- Imagens claras, com fundo simples, sem excesso de detalhes ou elementos distrativos.
- Registre a origem e a licença de imagens de terceiros em `CREDITS.md` nesta pasta.
- Toda imagem com significado precisa de texto alternativo (`alt`) definido nos dados da atividade.
